# SEO article drafts

This folder is the article draft queue consumed by `tools/seo/build_articles.py` in the main codebase. Each draft is a Markdown file with YAML front matter (title, description, slug, date, cluster, target_page, internal_links, sources, status). The build script renders drafts with `status: draft` for review and publishes those marked `status: approved` into the site, updating the sitemap. Drafts follow the house rules in `CLAUDE.md`: sourced statistics or none, no practice or location counts, no pricing, no personal names, and an illustrative-AI-preview disclaimer wherever a preview is shown.
